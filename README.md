# Video Sync — Android-приложение + Python-сервер

Приложение следит за новыми видео в галерее телефона, сжимает их в **480p**
и отправляет на ваш сервер. На сервере есть вход по логину/паролю и веб-страница,
где видны видео — свои у обычного пользователя, и **видео всех пользователей**
у администратора.

Главное поведение:
- **Нет интернета?** Видео не теряется — встаёт в очередь и уходит, как только
  появится связь (этим занимается WorkManager, он сам ждёт сеть и повторяет).
- **480p** — на сервер уходит сжатая копия, оригинал в галерее не трогается.
- Дубли не отправляются (приложение помнит, что уже загружено).

```
video-sync/
├── server/       ← Python-сервер (запускается первым)
└── android/      ← проект Android Studio (из него собирается APK)
```

---

## 1. Запуск сервера

Нужен Python 3.9+.

```bash
cd server
pip install -r requirements.txt
python main.py
```

Сервер поднимется на `http://0.0.0.0:8000`.

- Веб-интерфейс: откройте в браузере `http://АДРЕС_СЕРВЕРА:8000`
- **Админ по умолчанию:** логин `admin`, пароль `admin123`
  (админ видит видео всех пользователей — поменяйте пароль, см. ниже).

Видео сохраняются в `server/data/videos/`, пользователи и список видео — в
`server/data/app.db` (SQLite).

### Какой адрес вписывать в приложении

- **Телефон и компьютер в одной Wi-Fi сети:** узнайте локальный IP компьютера
  (Windows — `ipconfig`, Mac/Linux — `ifconfig`/`ip a`), например `192.168.1.50`.
  В приложении укажите `http://192.168.1.50:8000`.
- **Эмулятор Android на том же ПК:** адрес `http://10.0.2.2:8000`
  (это специальный адрес, по которому эмулятор видит ваш компьютер).
- **Доступ из интернета** (не только по Wi-Fi): нужно разместить сервер на
  VPS/хостинге и желательно включить HTTPS (см. раздел «Боевой режим»).

## 2. Сборка APK

Есть два пути:

- **Через GitHub (без Android Studio) — самый простой.** GitHub соберёт APK в
  облаке, вы только скачаете готовый файл. Пошагово — в файле
  `GITHUB_СБОРКА_APK.md`. Нужный workflow уже лежит в `.github/workflows/`.
- **Локально в Android Studio** — если хотите собирать на своём компьютере
  (раздел ниже).

### 2a. Сборка APK в Android Studio

1. Установите **Android Studio** (если ещё нет): https://developer.android.com/studio
2. **File → Open** и выберите папку `android`.
3. Дождитесь, пока Android Studio сам докачает Android SDK и зависимости
   (Gradle Sync). Первый раз это занимает несколько минут — нужен интернет.
4. Соберите APK: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Когда сборка закончится, снизу появится ссылка **locate** — по ней откроется
   папка с файлом `app-debug.apk`
   (путь: `android/app/build/outputs/apk/debug/app-debug.apk`).
6. Перекиньте этот `.apk` на телефон и установите
   (на телефоне нужно разрешить «установку из неизвестных источников»).

> APK здесь не приложен намеренно: его нельзя собрать без Android SDK, а SDK
> ставится вместе с Android Studio на вашей машине. Весь код готов — остаётся
> нажать Build.

### Сборка из командной строки (по желанию)

Если Android SDK уже установлен и переменная `ANDROID_HOME` настроена:

```bash
cd android
./gradlew assembleDebug        # Linux/Mac
gradlew.bat assembleDebug      # Windows
```

APK появится в `app/build/outputs/apk/debug/`.

## 3. Как пользоваться

1. Запустите сервер.
2. Установите и откройте приложение на телефоне.
3. Впишите адрес сервера, придумайте логин/пароль → **Зарегистрироваться**.
4. Разрешите приложению доступ к видео (запросит при первом запуске).
5. Снимите или сохраните новое видео в галерею. В течение ~15 минут (или сразу,
   если нажать «Проверить и отправить сейчас») оно сожмётся в 480p и уйдёт на
   сервер.
6. Откройте сайт, войдите тем же логином — увидите своё видео.
   Войдите как `admin` — увидите видео всех.

## 4. Как это устроено (коротко)

**Приложение (Kotlin):**
- `ui/MainActivity.kt` — экран входа/регистрации и управление синхронизацией.
- `work/UploadWorker.kt` — фоновая задача: находит новые видео в `MediaStore`,
  сжимает и грузит.
- `work/SyncScheduler.kt` — планирует задачу (периодически каждые 15 мин +
  сразу), с условием «есть сеть». Здесь же переключение на «только Wi-Fi».
- `net/VideoCompressor.kt` — сжатие в 480p через Media3 Transformer.
- `net/Api.kt` — обращения к серверу (регистрация, вход, загрузка).
- `data/Prefs.kt` — хранит токен, адрес сервера и список уже загруженных видео.

**Сервер (Python / Starlette):**
- `POST /api/register`, `POST /api/login` — выдают токен приложению.
- `POST /api/upload` — принимает видеофайл (нужен токен).
- `GET /api/my-videos` — список загруженного.
- Веб-страницы `/`, `/login`, `/register`, плеер `/video/{id}`.

## 5. Боевой режим (важно перед реальным использованием)

- **Поменяйте пароль админа.** Сейчас это `admin / admin123` — задаётся в
  `server/main.py` в функции `init_db()`.
- **Задайте секретный ключ** для токенов через переменную окружения:
  `SECRET_KEY=ваш_длинный_случайный_ключ python main.py`
  (иначе при перезапуске сервера все токены станут недействительными).
- **Включите HTTPS.** Сейчас приложение ходит по HTTP (в манифесте разрешён
  `usesCleartextTraffic`). Для интернета поставьте сервер за nginx/Caddy с
  сертификатом и в приложении используйте `https://...`. После этого уберите
  `android:usesCleartextTraffic="true"` из манифеста.
- **Ограничение по трафику.** Чтобы грузить только по Wi-Fi, в
  `SyncScheduler.kt` поменяйте `NetworkType.CONNECTED` на `NetworkType.UNMETERED`.

## 6. Важно про согласие и закон

Используйте это приложение **только на своих устройствах или с явного согласия
владельца телефона**. Регистрация в приложении — это и есть осознанное действие
пользователя. Скрытая отправка чужих видео на сервер — это слежка, она незаконна
в большинстве стран и запрещена правилами Google Play. Не делайте так.
