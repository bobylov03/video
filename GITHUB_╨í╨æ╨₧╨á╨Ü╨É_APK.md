# Сборка APK через GitHub (без Android Studio)

GitHub сам соберёт APK в облаке — у них на серверах уже установлен Android SDK.
Вам нужно только залить проект и скачать готовый файл.

## Шаг 1. Создать репозиторий

1. Зайдите на https://github.com → кнопка **New** (новый репозиторий).
2. Назовите, например, `video-sync`. Можно **Private** (приватный) — сборка
   работает и для приватных.
3. Нажмите **Create repository**.

## Шаг 2. Залить проект

Вариант А — через сайт (проще):
1. На странице репозитория нажмите **Add file → Upload files**.
2. Перетащите **всё содержимое папки `video-sync`** (папки `android`, `server`,
   `.github`, файлы README). Важно: папка `.github` должна попасть в репозиторий —
   в ней лежит инструкция сборки.
3. Внизу нажмите **Commit changes**.

Вариант Б — через командную строку (если умеете пользоваться git):
```bash
cd video-sync
git init
git add .
git commit -m "Video Sync: приложение и сервер"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/video-sync.git
git push -u origin main
```

## Шаг 3. Дождаться сборки

1. На странице репозитория откройте вкладку **Actions**.
2. Увидите запущенную задачу **«Сборка APK»** (стартует сама после загрузки).
   Если не стартовала — откройте её и нажмите **Run workflow**.
3. Подождите ~3–5 минут, пока напротив появится зелёная галочка.

## Шаг 4. Скачать APK

1. Кликните на завершённую задачу во вкладке **Actions**.
2. Внизу страницы, в разделе **Artifacts**, будет файл **video-sync-apk**.
3. Скачайте его (придёт zip), распакуйте — внутри `app-debug.apk`.
4. Перекиньте на телефон и установите (разрешите «установку из неизвестных
   источников»).

Готово. Каждый раз, когда вы меняете код и заливаете его на GitHub, APK
пересобирается автоматически — просто снова скачиваете свежий из Actions.

---

**Если во вкладке Actions ничего нет:** проверьте, что папка `.github/workflows/`
с файлом `build-apk.yml` действительно загрузилась в репозиторий (GitHub иногда
пропускает скрытые папки при перетаскивании — тогда создайте файл вручную через
**Add file → Create new file**, путь `.github/workflows/build-apk.yml`, и вставьте
содержимое из проекта).
